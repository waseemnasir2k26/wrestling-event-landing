# Iron Fist Wrestling, event landing demo

Single-page landing for a fictional pro wrestling night: countdown, match card, roster, ticket tiers, venue, FAQ. One `index.html`, Tailwind CDN, Google Fonts, no build step.

- Ticket buttons are placeholders; there is a slot at `#eventbrite-mount` for an Eventbrite embed
- Event date is set in `index.html` (`const EVENT`) and is already in the past; update it
- Roster portraits are placeholder blocks

Open `index.html` or deploy to any static host.
